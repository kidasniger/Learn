# Learn

Appli Android de transcription vocale hors-ligne (français) basée sur whisper.cpp.

1. Pousse ce dépôt sur GitHub : l'onglet **Actions** compile l'APK automatiquement.
2. Télécharge l'artefact `learn-debug-apk`, installe l'APK.
3. Dans l'appli : "Choisir le modèle" → sélectionne `ggml-large-v3-turbo-q5_0.bin`.
4. Enregistre, arrête, le texte apparaît.
